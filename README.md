My secodn internal tool.

It is a simple prospecting tool that allows to, making use of Google Places API, make a table with information about businesses gathered with 3 filters, keyword, location and max review count.

Used for prospecting for my first MVP, localli.

Composed of nextjs, react, tailwind css, drizzle, Google Places API, neon for database and deployed on Vercel. No authentication required as it is a personal internal tool.
